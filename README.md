# 项目1：会议室预约管理系统
**技术栈**：SpringBoot、MyBatis‑Plus、MySQL、Redis、JWT、BCrypt、Vue3、Element‑Plus
面向企业内部的会议室预约前后端分离系统，实现会议室维护、预约申请、时间冲突校验、权限管控。
- 封装统一返回、全局异常与参数校验；基于JWT+拦截器完成登录鉴权，区分管理员/普通用户接口权限。
- BCrypt加密用户密码；Redis缓存会议室信息，数据库建索引优化分页查询；业务层实现预约时间冲突校验与预约状态流转，完成前后端联调。

# 项目2：报表统计服务
**技术栈**：SpringBoot、MyBatis‑Plus、MySQL、Redis、EasyExcel、Quartz
针对大数据量报表导出超时、内存溢出问题开发报表服务。
- 采用异步任务+文件预生成方案，通过Quartz定时任务预处理报表数据；Redis缓存任务状态，前端轮询下载。
- 分批读写Excel避免全量加载内存；数据库优化查询，解决大报表接口超时OOM问题。
